# <ShadowBlueprint/> — Portfolio

Portfolio personnel de **Djaha Edmond Daryl**, développeur logiciel basé à Douala, Cameroun.

Ce portfolio a été conçu pour présenter mon parcours, mes compétences techniques, mes projets réalisés ainsi que mon CV et mes informations de contact.

Le projet est développé avec **React**, **Vite** et **Tailwind CSS** et est destiné à être déployé sur **Vercel**.

---

## Présentation

L'objectif de ce portfolio est de disposer d'un espace professionnel permettant de présenter :

- mon profil de développeur logiciel ;
- mes compétences techniques ;
- mes projets ;
- mon parcours académique ;
- mon CV ;
- mes coordonnées ;
- mes liens professionnels.

L'interface est conçue pour être responsive et s'adapter aux ordinateurs, tablettes et smartphones.
